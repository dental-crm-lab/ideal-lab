# IDEAL Lab

Доска заказов, приём заявок от врачей и финансовый учёт для CAD-CAM лаборатории IDEAL.
Самостоятельный веб-сервис (не зависит от Claude) — свой бэкенд, своя база, реальная загрузка файлов сканов, работает как обычный сайт, PWA и десктоп-приложение (Windows).

## Что внутри

- `server/` — бэкенд (Node.js + Express + Socket.IO): хранит данные в `server/data/db.json`, файлы сканов — в `server/data/uploads/`, отдаёт живые обновления через WebSocket.
- `public/` — фронтенд: одна страница `index.html` + PWA-манифест и иконки.
- `electron/` — десктопная обёртка (Windows .exe): тонкий клиент, который просто открывает адрес вашего сервера в отдельном окне.

## 1. Развернуть на Railway (через GitHub)

**Шаг 1 — залить код на GitHub.** В папке проекта:

```bash
git init
git add .
git commit -m "IDEAL Lab"
git branch -M main
git remote add origin https://github.com/<ваш-аккаунт>/ideal-lab.git
git push -u origin main
```

(Репозиторий на GitHub создайте заранее — «New repository», можно приватный.)

**Шаг 2 — Railway.**
1. Зайдите на [railway.app](https://railway.app), войдите через GitHub.
2. «New Project» → «Deploy from GitHub repo» → выберите `ideal-lab`.
3. Railway сам определит Node.js-проект и запустит `npm install && npm start`.
4. **Важно — постоянное хранилище.** Без него база и файлы будут исчезать при каждом передеплое. В настройках сервиса откройте вкладку **Volumes** → «New Volume» → точка монтирования `/data`. Затем во вкладке **Variables** добавьте переменную `DATA_DIR` со значением `/data`.
5. Во вкладке **Settings → Networking** нажмите «Generate Domain» — получите публичный адрес вида `ideal-lab-production.up.railway.app`. Он и нужен врачам, сотрудникам и десктоп-приложению.

Готово — сайт публичный, доступен всем по ссылке, без каких-либо ограничений по аккаунтам (в отличие от предыдущей версии на Claude Artifacts).

## 2. PWA (устанавливается как приложение из браузера)

Ничего дополнительно делать не нужно — как только сайт развёрнут на Railway:
- **Компьютер (Chrome/Edge):** в адресной строке появится значок установки — можно «поставить» сайт как приложение с иконкой на рабочем столе.
- **Android:** меню браузера → «Добавить на главный экран».
- **iPhone (Safari):** «Поделиться» → «На экран «Домой»».

## 3. Десктоп-приложение для Windows (.exe)

Готовые .exe весят ~75 МБ каждый (это нормально для Electron — внутри свой браузерный движок), поэтому в чат их отправить нельзя — собрать их можно одним из двух способов:

**Способ А — GitHub Actions (проще всего, ничего локально ставить не нужно).**
В репозитории уже есть `.github/workflows/build-windows.yml`. После того как вы запушите код на GitHub (шаг 1):
1. На GitHub откройте вкладку **Actions** → workflow «Build Windows app» → **Run workflow**.
2. Через 2-3 минуты в результатах запуска появится вложение **IDEAL-Lab-Windows** — скачайте и распакуйте, внутри будут оба .exe.

Workflow также запускается автоматически при любом изменении папки `electron/`.

**Способ Б — собрать локально** (на Windows, либо на Linux/macOS с установленным `wine` — нужен для встраивания иконки):

```bash
cd electron
npm install
npm run dist:win
```

Файлы появятся в `electron/dist/`:
- **`IDEAL Lab Setup 1.0.0.exe`** — обычный установщик (рекомендуется для Эмиля).
- **`IDEAL Lab 1.0.0.exe`** — portable-версия, запускается без установки.

При первом запуске приложение попросит **адрес сервера** — вставьте туда домен из Railway (шаг 1.5), например `ideal-lab-production.up.railway.app`. Дальше приложение просто открывает ваш сайт в отдельном окне — все данные и обновления всегда живут на сервере, а не в самом .exe. Если адрес сервера потом изменится — его можно поменять через меню **IDEAL Lab → Сменить адрес сервера…**, пересобирать .exe заново не нужно.

## 4. Локальный запуск для разработки

```bash
npm install
npm start
```

Откройте `http://localhost:3000`. База данных создаётся автоматически в `server/data/`.

## Вход в приложение

- **Сотрудник:** «Я сотрудник лаборатории» → «Эмиль» → PIN `1234`. Сразу смените PIN в разделе «Сотрудники».
- **Врач:** «Я врач / клиника» → номер телефона (при первом входе — имя и клиника). Теперь это по-настоящему открытая ссылка — любой врач может зайти сам, аккаунт Claude не нужен.
- В «Настройках» есть кнопка **«Очистить демо-данные»** — уберите тестовые заказы и сотрудников, когда будете готовы к реальной работе.

## Загрузка файлов сканов

Работает по-настоящему (drag-and-drop или выбор файла), до 150 МБ на файл — сохраняются на сервере в `server/data/uploads/`. Поле для ссылки (Google Диск и т.п.) тоже осталось — как запасной вариант.

## Технические детали

- Данные хранятся в одном JSON-файле (`server/data/db.json`) — этого более чем достаточно для объёма одной лаборатории. Если объём вырастет на порядки, стоит перейти на настоящую БД (Postgres на Railway подключается в одну кнопку) — дайте знать, если понадобится.
- Живые обновления доски между устройствами — через Socket.IO, без перезагрузки страницы.
- PIN-вход — простая защита внутри лаборатории, не полноценная авторизация с ролями/паролями. Если понадобится более строгий доступ — можно добавить отдельно.
